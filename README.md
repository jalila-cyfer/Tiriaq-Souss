# 🛍️ appStore

## Présentation du projet

**appStore** est une application web développée avec ASP.NET Core et Blazor en utilisant le framework .NET 8.

Ce projet a été réalisé dans le cadre d'un projet académique.

## 🛠️ Technologies utilisées

- C#
- ASP.NET Core
- Blazor
- .NET 8
- HTML
- CSS

## 📁 Structure du projet

```text
appStore/
│
├── Components/
├── Properties/
├── wwwroot/
│   └── images/
│       └── recipes/
│
├── appsettings.json
├── appStore.csproj
└── Program.cs
```

## ⚙️ Prérequis

Pour exécuter ce projet, vous devez disposer de :

- .NET 8 SDK
- Visual Studio 2022 ou supérieur
- Un navigateur web

## 🚀 Installation et exécution

1. Cloner le repository :

```bash
git clone URL_DU_REPOSITORY
```

2. Accéder au dossier :

```bash
cd appStore
```

3. Restaurer les dépendances :

```bash
dotnet restore
```

4. Lancer l'application :

```bash
dotnet run
```

5. Ouvrir l'adresse locale affichée dans le terminal.

## 🌐 Hébergement

Le projet est destiné à être déployé gratuitement sur Render à l'aide de Docker.
